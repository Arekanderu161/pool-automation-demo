## Ключевые методы для сценариев детского бассейна

| Группа | Метод и путь | Как используется в системе |
|---|---|---|
| Подписки (Webhook) | `POST /subscriptions`, `GET /subscriptions`, `DELETE /subscriptions` | Приём входящих событий в реальном времени (без polling). Требуется валидный HTTPS (без самоподписанных сертификатов). |
| Меню бота | `PATCH /me/commands`, `GET /me` | Настройка быстрых команд для родителей («Мои занятия», «Остаток абонемента», «Отправить справку»). |
| Сообщения | `POST /messages`, `PUT /messages`, `GET /messages`, `DELETE /messages` | Напоминания за 24 ч, обновление текста после нажатия кнопки, утренний список тренеру в `08:00`, вечерняя сводка владельцу в `21:00`. |
| Кнопки (Callback) | `POST /answers` | Мгновенный отклик на нажатия кнопок `Придём ✅`, `Перенести 🔄`, `Заболели 🤒`, а также отметки явки тренером. |
| Файлы (Справки) | `POST /uploads` | Загрузка/приём фото медсправок, отправленных родителями в чат бота. |
| Чаты и участники | `GET /chats/{chatId}`, `PATCH /chats/{chatId}`, `GET /chats/{chatId}/members`, `POST /chats/{chatId}/actions` | Проверка участников и отображение статуса «печатает» при ответе. |
| Разработка | `GET /updates` | Long polling для локальной отладки без публичного домена. |

## Неподтверждённые детали (нужно проверить при старте Этапа 2)

- Актуальные правила верификации и квоты на создание коммерческих ботов для ИП/ООО на портале `business.max.ru`.
- Необходимость установки корневого сертификата Минцифры (`russian_trusted_root_ca`) в среде сервера, если обращение к `platform-api2.max.ru` идёт из конкретного Linux/Docker-окружения.
