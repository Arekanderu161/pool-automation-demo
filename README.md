# Автоматизация детского бассейна «Family Time»

Живая интерактивная демо-версия: **https://arekanderu161.github.io/pool-automation-demo/**

Проект показывает владельцу и 2 администраторам детского бассейна **«Family Time»**, как уйти от Excel-таблиц, бумажных журналов и переписки в одном Android-телефоне к единой, лёгкой и надёжной системе — на простом языке без технических терминов и с акцентом на просмотр с телефона.

## Что внутри

- [`index.html`](index.html), [`styles.css`](styles.css), [`app.js`](app.js) — лёгкая интерактивная HTML-демка без сборщиков и внешних зависимостей (работает прямо в браузере, адаптирована под мобильные телефоны):
  - блок выгод с фильтром «Владельцу / Администраторам»;
  - **калькулятор экономии времени** с ползунками (часы в неделю, месяц и количество смен);
  - интерактивный мини-гид из 3 шагов и всплывающие подсказки-объяснения выгоды при каждом клике;
  - живой симулятор экрана администратора (переключение смены Елена / Влада, мобильный переключатель «Экран админа / Чат MAX», расписание, отметка явки в 1 клик, база семей и справок, итоги по тренерам и история действий);
  - симулятор **бота MAX и умного помощника** (кнопка «Придём ✅», болезнь со справкой, перенос на свободное окно, автоответ новому клиенту, предпросмотр утреннего списка тренеру и вечерней сводки владельцу);
  - сравнение «Было → Стало», сравнение цены и 4 простых шага запуска.
- [`docs/architecture.md`](docs/architecture.md) — архитектура 3 слоёв, модель данных (SQLite), сравнение готовых CRM, бюджет, 4 этапа внедрения и опросник перед стартом разработки.
- [`docs/max-bot-api-summary.md`](docs/max-bot-api-summary.md) — сводка подтверждённых методов MAX Bot API (`platform-api2.max.ru`).

## Как открыть локально

Достаточно открыть [`index.html`](index.html) двойным кликом в любом современном браузере — сервер и сборка не требуются.

## Дальнейшие этапы

1. **Этап 1 — Ядро + Веб-панель (MVP):** SQLite + 4 экрана + импорт из текущего Excel (отказ от бумажного журнала).
2. **Этап 2 — MAX Bot:** напоминания с кнопками за 24 ч, утренний список тренерам в `08:00`, приём фото справок.
3. **Этап 3 — Hermes Agent:** `no-agent` cron (0 ₽ за токены) для регулярных сводок + точечный LLM для разбора свободных сообщений и FAQ с подтверждением админа в 1 клик.
4. **Этап 4 — Пилот (3–5 дней):** параллельная работа с бумажным журналом для проверки в бою и полный переход.
